## 使用边界

- 本 Release 不包含 ARM64 或 Windows 包。
- 包内本地重建的 Linux 原生库未进行数字签名，请使用 SHA-256 和产品文件清单完成完整性校验。
- x86_64 图形界面验证使用麒麟 V10 x86_64 用户态环境及宿主机指令转换，不替代目标物理机或桌面云的最终准入验收。
- GaussDB JDBC 驱动与数据库原生工具不随客户端分发。
- M 兼容模式按基础数据库能力使用，不声明支持 PL/SQL 调试。
- Package 完整编译和错误定位能力取决于目标数据库部署形态及服务端能力。

详细安装和操作方法见[使用指南](./README.md)。
